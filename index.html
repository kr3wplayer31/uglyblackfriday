Questions? Answered.

🚚 How long does shipping take?

Every sweater is printed and fulfilled to order — we do not pull them off a warehouse shelf. Please order early: order by December 18 for Christmas delivery. That date is on our countdown for a reason.

↩️ What if it does not fit?

We offer 30-day returns. And the easiest return is the one you never make: our sweaters run small, so order one size up for a cozier fit and check the size chart before you buy.

📏 How do the sizes run?

Snug. The all-over-print sweaters use a slimmer Euro-style cut, and the classic sweatshirts are standard unisex. Full measurements for both are in our size chart & fit guide — measure a sweater you love, compare, and size up if you are between sizes.

🔔 How do the bells & light-up add-ons work?

In the Design Studio you can mark spots for real add-ons: jingle bells (+$9.99) sewn on by hand, and a real light string (+$14.99). The lights are a removable battery string with an AA battery pack — take the pack out before washing, and keep it dry.
